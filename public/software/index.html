Free encrypted notepad v1.3.0

Notes in one file you own, optionally encrypted at rest with AES-256. Offline dictation with local speech recognition, syntax highlighting, inline images and recordings, groups, tags and instant search.

Free network scanner v1.6.0

Scans multiple networks using ARP, ping, port probes, mDNS and SSDP. It fingerprints services, identifies MAC vendors, classifies devices, opens RDP, SSH and web connections, exports CSV or HTML, and includes a headless CLI for scripts and RMM work.

KillerScan was the first app I built. I made it out of necessity because the alternatives were all bad. I use it any time I am on a new network and need to see what is plugged in.

KillerPivotPer-Identity Validated Org-Toggle

Switch between Microsoft 365 tenants in PowerShell without firing commands at the wrong one. It disables the auth broker to force a real sign-in prompt, then asks the session which tenant it actually landed in and verifies it before you touch anything.

PS> Install-Module KillerPivot -Scope CurrentUser

KillerScripts

Every tool in the killer-scripts repo, available as a command in any PowerShell session. Each script is pulled fresh from GitHub the moment you run it, with a local cache as an offline fallback. All 18 get their own command and a short alias, so typing urt runs the Universal Rename Tool.

PS> Install-Module KillerScripts -Scope CurrentUser
